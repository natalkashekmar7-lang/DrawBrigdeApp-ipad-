# DrawBridge — прототип (збірка через GitHub Actions, без Mac)

## Ідея
- Код лежить у GitHub-репозиторії
- При кожному пуші GitHub Actions на macOS-runner автоматично збирає **непідписаний** .ipa
- Ви завантажуєте .ipa на Windows і підписуєте+встановлюєте через **Sideloadly**
  своїм звичайним (безкоштовним) Apple ID

Жодного Mac не потрібно — ні свого, ні орендованого.

## Крок 1 — завантажте цей проєкт у GitHub
1. Створіть новий приватний репозиторій на github.com
2. Завантажте туди всю папку `DrawBridgeApp` (можна прямо через веб-інтерфейс
   "Add file → Upload files", або через git push, якщо звично)
3. GitHub автоматично запустить workflow (файл `.github/workflows/build.yml`)
   — перевірити прогрес: вкладка **Actions** у репозиторії

## Крок 2 — заберіть готовий .ipa
1. В Actions відкрийте останній запуск → внизу розділ **Artifacts**
2. Завантажте `DrawBridge-unsigned-ipa` (це .zip, всередині — .ipa)

## Крок 3 — встановіть на iPad через Sideloadly (Windows)
1. Встановіть Sideloadly: https://sideloadly.io
2. Підключіть iPad кабелем до Windows
3. Перетягніть `DrawBridge-unsigned.ipa` у Sideloadly
4. Вкажіть свій Apple ID (звичайний, безкоштовний — платний Developer акаунт не потрібен)
5. Натисніть Start — Sideloadly підпише .ipa і встановить на iPad
6. На iPad: Налаштування → Основні → VPN і керування пристроєм →
   довірити профілю розробника з вашим Apple ID (один раз)
7. Через 7 днів застосунок перестане запускатись (обмеження безкоштовного
   Apple ID) — просто повторіть крок 3-5 у Sideloadly, дані не губляться

## Крок 4 — перевірка
1. Запустіть застосунок DrawBridge на iPad — побачите "Слухаємо на порту 51234"
2. На Windows підключіть iPad кабелем і запустіть `windows_usb_bridge.py`
   (з попередньої відповіді) — отримаєте IPv6-адресу тунелю
3. Підключіться TCP-клієнтом з Windows до цієї адреси на порту 51234,
   надішліть тестовий текст — він з'явиться на екрані iPad

## Якщо щось не так
- Actions показує помилку збірки → напишіть мені текст помилки, розберемось
- Sideloadly не бачить iPad → перевірте, чи встановлено драйвери Apple
  (той самий Apple Mobile Device Service з попереднього кроку)
- Apple ID просить двофакторку — це нормально, Sideloadly підтримує 2FA
